**Milestone 2 – Inventory & Delivery Analytics:**

---

**Project Overview:**

This milestone focuses on developing interactive inventory and delivery analytics dashboards using Microsoft Power BI. Building on the data model created in Milestone 1, it provides insights into inventory performance, delivery efficiency, and regional trends through KPIs and visualizations.

---

**Objective:**

- Develop Inventory and Delivery dashboards.
- Analyze inventory turnover and delivery performance.
- Implement product and regional drill-downs.
- Perform trend and variance analysis.

---

**Dataset:**

- **Dataset:** DataCo Smart Supply Chain Dataset
- **Source:** Kaggle

---

**Dashboard Highlights:**

- Inventory Turnover Analysis
- Delivery Performance Analysis
- On-Time vs Delayed Deliveries
- Inventory Value by Category
- Regional Shipment Analysis
- Trend Analysis
- Interactive Filters and Drill-Downs

---

**Tools Used:**

- Microsoft Power BI
- Power Query Editor
- DAX
- GitHub

---

---

**Outcome:**

Successfully developed interactive Inventory and Delivery Analytics dashboards with key KPIs, trend analysis, and drill-down capabilities, providing actionable insights into supply chain performance.

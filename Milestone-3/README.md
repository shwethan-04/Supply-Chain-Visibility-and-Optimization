**Milestone 3 – Supplier & Transportation Analytics:**

This milestone focuses on analyzing supplier performance and transportation operations using Microsoft Power BI. The goal is to build dashboards that provide insights into supplier reliability, transportation costs, shipment trends, and overall logistics performance.

**Objective:**

- Analyze supplier performance and reliability.
- Monitor transportation costs and shipment trends.
- Evaluate route and carrier performance.
- Create business KPIs using DAX.
- Develop interactive Power BI dashboards.

**Dataset:**

**DataCo Global Supply Chain Dataset**

The dataset contains information related to suppliers, products, customers, shipments, transportation, and sales.

**Tools Used:**

- Microsoft Power BI Desktop
- Power Query Editor
- DAX (Data Analysis Expressions)
- GitHub

**Status:**

This milestone is currently in progress. The Supplier Performance Dashboard and Transportation Analytics Dashboard will be implemented as part of this milestone.

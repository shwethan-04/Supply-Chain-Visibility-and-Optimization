# Supply Chain Visibility & Optimization

## Infosys Springboard Virtual Internship

This repository contains my project work completed as part of the **Infosys Springboard Virtual Internship – Data Visualization Project**.

The project focuses on developing an interactive **Power BI dashboard** that provides end-to-end visibility into supply chain operations. It integrates inventory, delivery, supplier, transportation, and warehouse data to generate meaningful insights and support data-driven decision-making.

## Project Objectives

- Clean and transform supply chain data.
- Design an efficient Star Schema data model.
- Create reusable DAX measures and business KPIs.
- Analyze inventory and delivery performance.
- Evaluate supplier and transportation efficiency.
- Monitor warehouse operations.
- Develop an interactive executive-level Power BI dashboard.

## Project Milestones

### Milestone 1 – Data Modelling & KPI Foundation
- Data cleaning and transformation.
- Star Schema data modelling.
- Fact and Dimension table creation.
- DAX measures and core KPI development.

### Milestone 2 – Inventory & Delivery Analytics
- Inventory performance analysis.
- Inventory turnover monitoring.
- Delivery performance dashboard.
- Regional and product-level analysis.

### Milestone 3 – Supplier & Transportation Analytics
- Supplier performance scorecards.
- Supplier reliability analysis.
- Transportation cost analysis.
- Route and carrier performance evaluation.

### Milestone 4 – Warehouse Analytics & Final Dashboard
- Warehouse efficiency analysis.
- Utilization and throughput monitoring.
- Executive overview dashboard.
- Final testing, optimization, and documentation.
